Lab Module 01

🌐 Network Reconnaissance (Ethical Lab)

লোকাল ল্যাব ও নেটওয়ার্ক ইন্টারফেস এনালাইসিসের জন্য ব্যাসিক ইনফরমেশন এবং কানেক্টিভিটি রাউটিং ট্র্যাকিং।

Basic Network Interfaces CLI Envs
ipconfig /all
Windows: আপনার device এর IP, DNS, MAC info দেখায়।
ip a
Linux: Network interface configuration ও IP bindings প্রিন্ট করে।
Connectivity & Domain DNS Analysis Routing
ping google.com
Internet Working Test: ইন্টারনেট একটিভ কিনা তা ICMP প্যাকেটের মাধ্যমে টেস্ট করে।
traceroute google.com
Route Tracking: ডাটা কোন কোন রাউটার বা গেটওয়ে (Route) দিয়ে পাস হচ্ছে তা ট্র্যাক করে।
nslookup example.com
DNS Lookup: Domain নামকে নির্দিষ্ট IP address এ কনভার্ট করে রেকর্ড দেখায়।
dig example.com
Advanced DNS Analysis: ডোমেইনের ডিটেইলড DNS রেকর্ড অ্যানালাইসিস করতে সাহায্য করে।
Lab Module 02

🔎 Port & Service Discovery (Lab Only)

লোকাল অডিটিং সেশনের জন্য ওপেন সকেট এবং সার্ভিসের ব্যানার ও ভার্সন আইডেন্টিফিকেশন টুলস।

📘 Audit Example: সার্ভার হার্ডেনিং বা নেটওয়ার্ক সিকিউরিটি বেসলাইন অডিট করার জন্য এগুলো ব্যবহার করা হয়।
Port Scanning & Sockets Binding Nmap / Sockets
nmap -sV 192.168.1.1
Bangla: টার্গেটে কোন কোন পোর্ট ওপেন আছে এবং ব্যাকএন্ডে কোন সার্ভিস রানিং তার ভার্সন ডিটেক্ট করে।
ss -tulpn
Bangla: আপনার লোকাল সিস্টেমে কোন পোর্ট কোন নির্দিষ্ট অ্যাপ্লিকেশন বা সার্ভিস ইউজ করছে তা ডিটেইলস দেখায়।
nmap -sS -sV target.com
Stealth Core: ল্যাব এনভায়রনমেন্টে SYN stealth স্ক্যানিং ও সার্ভিস ফিঙ্গারপ্রিন্টিং অপারেশন।

🖥️ System Analysis & Blue Team Diagnostics

অ্যাক্টিভ মেমোরি প্রসেস ট্র্যাকিং, নেটওয়ার্ক সকেট কানেকশন এনালাইসিস এবং ব্লু টিম সিকিউরিটি লগ অডিটিং।

Process & Open Port Diagnostics Processes
tasklist
Windows: বর্তমানে মেমোরিতে রানিং সব অ্যাপ্লিকেশন এবং ব্যাকগ্রাউন্ড প্রসেস লিস্ট শো করে।
ps aux
Linux: সিস্টেমের রানিং সকল টাস্কের ডিটেইলড স্ট্যাটাস আর্কিটেকচার দেখায়।
netstat -ano
Bangla: কোন অ্যাপ বা প্রসেস আইডি (PID) বর্তমানে ইন্টারনেট কানেকশন হোল্ড করে আছে বা পোর্ট ওপেন রেখেছে তা দেখায়।
File Integrity & SIEM Logs Integrity
sha256sum file
Linux Checksum: ফাইলে কোনো প্রকার অননুমোদিত মডিফিকেশন হয়েছে কিনা তা ডিটেক্ট করতে ক্রিপ্টোগ্রাফিক হ্যাশ তৈরি করে।
certutil -hashfile file SHA256
Windows Checksum: উইন্ডোজ বাইনারি বা ফাইলের ইন্টিগ্রিটি চেকসাম ভেরিফিকেশন প্রোটোকল।
Get-WinEvent -LogName Security
Bangla: উইন্ডোজের ইন্টারনাল লগইন হিস্টোরি অডিট এবং ফেইলড বা সাসপিসিয়াস লগইন ডিটেক্ট করতে সিকিউরিটি ইভেন্ট অডিট করে।
journalctl -xe
Linux Log: সিস্টেম এরর, সার্ভিস ফেইলর এবং হোস্ট ডিফেন্স লেভেলের রিয়েল-টাইম লগ ট্র্যাকিং।

🔬 Web Security & Safe Theory

ওয়েবসাইট টেকনোলজি ফিঙ্গারপ্রিন্টিং, হেডার সিকিউরিটি অ্যানালাইসিস এবং সিকিউর কোডিং ডেমোনেস্ট্রেশন।

Technology Mapping & Subdomain Discovery Target Scan
whatweb example.com
Bangla: টার্গেট ওয়েবসাইট কোন সিএমএস, প্লাগইন, ডাটাবেস বা সার্ভার টেকনোলজি ইউজ করছে তা আইডেন্টিফাই করে।
curl -I https://example.com
Header Analytics: ওয়েবসাইটের HTTP হেডার রেসপন্স ডেটা এবং মিসকনফিগারেশন চেক করার মেকানিজম।
whois example.com
Bangla: ডোমেইন ওনারশিপ ইনফরমেশন, রেজিস্ট্রেশন ডিটেইলস এবং নেমসার্ভার রেকর্ডস এনালাইসিস।
nikto -h https://target.com
Vulnerability Scanner: ওয়েব সার্ভারের বিপজ্জনক বা আউটডেটেড ফাইল এবং সিকিউরিটি হোলস ডিটেকশনের জন্য ডিফেনসিভ অডিট।
dig A example.com
DNS Layer: ডোমেইনের নির্দিষ্ট IPv4 Address ম্যাপিং আইসোলেশন।
subfinder -d example.com
Bangla: সিকিউরিটি অ্যাসেসমেন্টের জন্য টার্গেট ডোমেইনের অধীনে থাকা সব সাবডোমেন আইডেন্টিফাই বা ম্যাপিং করার জন্য ব্যবহার করা হয়।

📶 WiFi Network Recovery Guide (Legal & Educational)

শুধুমাত্র নিজের হোস্ট পিসি এবং অথোরাইজড ল্যাব ওয়াইফাই নেটওয়ার্কের কানেকশন ক্রেডেনশিয়াল ট্রাবলশুটিং প্রোটোকল।

⚠️ SECURITY LIMITS

  • শুধুমাত্র নিজের PC এবং নিজের WiFi network-এর জন্য ব্যবহারযোগ্য।
  • অন্যের WiFi বা যেকোনো নেটওয়ার্ক অননুমোদিত অ্যাক্সেস করা সম্পূর্ণ অবৈধ।
Windows WLAN Profile Utilities WLAN CMD
netsh wlan show profiles
Step 1: তোমার PC-তে আগে কানেক্ট করা সব WiFi নামের Wireless Profile List রিটার্ন করে।
netsh wlan show profile name="WiFiName"
Step 2: ওই WiFi-এর ফুল কনফিগারেশন, সিকিউরিটি এনক্রিপশন টাইপ (WPA2/WPA3) এবং সেটিং স্ট্রাকচার দেখায়।
netsh wlan show profile name="WiFiName" key=clear
Step 3: নিজের নেটওয়ার্কের ক্রেডেনশিয়াল ভুলে গেলে তা প্লেইন টেক্সট মোডে ভেরিফাই করার কম্যান্ড।

🧠 How it Works Mechanics

Windows ওএস ওয়ারলেস প্রোফাইল ম্যানেজমেন্ট ডাটাবেসে ক্রেডেনশিয়াল ইন্টারনালি সেভ করে রাখে। এডমিন প্রিভিলেজসহ key=clear প্যারামিটার পাস করলে উইন্ডোজ সাবসিস্টেম তার ডিস্ক্রিপ্টেড ফর্ম বা সেভড কি প্লেইন টেক্সট আকারে শো করে। এটি পূর্বে কানেক্টেড হওয়া নেটওয়ার্ক ক্রেডেনশিয়াল রিকভারি ও আইটি ট্রাবলশুটিং সেশনে কার্যকর ভূমিকা রাখে।
