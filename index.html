Basic Network Interfaces CLI Tools
ipconfig /all
👉 Windows: আপনার device এর IP, DNS, MAC info দেখায়।
ip a
👉 Linux: Network interface configurations এবং IP bindings প্রিন্ট করে।
Connectivity & DNS Mapping NETWORK
ping google.com
👉 ICMP Echo Request পাঠিয়ে Internet working বা active কিনা তা টেস্ট করে।
traceroute google.com
👉 প্যাকেট গন্তব্যে পৌঁছাতে কোন কোন রাউটার বা হপ অতিক্রম করছে তা ট্র্যাক করে।
nslookup example.com
👉 Domain নামকে নির্দিষ্ট IP address এ কনভার্ট করে রেকর্ড বিশ্লেষণ করে।
dig example.com
👉 Advanced DNS record query টুল (A, MX, TXT records ট্র্যাকিং)।
Lab Layer 02

🔎 Port & Service Discovery

ল্যাব অডিটিং সেশনের জন্য ওপেন পোর্ট এবং ব্যাকএন্ড রানিং সার্ভিস ট্র্যাকিং প্রোটোকল।

💡 Defensive Usage: নিজের লোকাল সার্ভার অডিটিং ও নেটওয়ার্ক সিকিউরিটি বেসলাইন চেক করার জন্য অত্যন্ত উপযোগী।
Auditing Services & Sockets AUDIT
nmap -sV 192.168.1.1
👉 কোন কোন পোর্ট ওপেন আছে এবং ব্যাকএন্ডে কোন সার্ভিসের কোন ভার্সন রানিং তা ডিটেক্ট করে।
ss -tulpn
👉 লোকাল সিস্টেমে কোন পোর্ট কোন নির্দিষ্ট অ্যাপ্লিকেশন বা প্রসেস ইউজ করছে তা লিসেনিং সকেটসহ দেখায়।
nmap -sS -sV target.com
👉 Stealth SYN সোর্স স্ক্যান এবং রানিং সার্ভিস আইডেন্টিফিকেশন প্রোটোকল (ল্যাব এনভায়রনমেন্ট অনলি)।

🖥️ System Analysis & Logs

Runtime Diagnostics & Network States SYS
tasklist
👉 Windows সিস্টেমে বর্তমানে রানিং অ্যাপ্লিকেশন এবং ব্যাকগ্রাউন্ড প্রসেস মেমোরিসহ প্রিন্ট করে।
ps aux
👉 Linux এনভায়রনমেন্টে রানিং সকল টাস্কের ডিটেইলড স্ট্যাটাস আর্কিটেকচার দেখায়।
netstat -ano
👉 কোন অ্যাপ বর্তমানে ইন্টারনেট কানেকশন হোল্ড করে আছে, কোন লোকাল পোর্ট ওপেন এবং প্রসেস আইডি (PID) অ্যানালাইসিস।
Blue Team Analytics & Log Pipeline LOGS
sha256sum file
👉 Linux ফাইলে কোনো অননুমোদিত পরিবর্তন হয়েছে কিনা তা যাচাই করার জন্য ইন্টিগ্রিটি চেকসাম জেনারেট করে।
certutil -hashfile file SHA256
👉 Windows সিস্টেমে বাইনারি বা ফাইলের ক্রিপ্টোগ্রাফিক হ্যাশ ভ্যালু ডিটেকশন প্রোটোকল।
Get-WinEvent -LogName Security
👉 Windows Security লগের রিয়েল-টাইম অডিট (যেমন: ইউজার লগইন হিস্টোরি এবং ফেইলড অ্যাটেম্পট ডিটেকশন)।
journalctl -xe
👉 Linux systemd এনভায়রনমেন্টের সিস্টেম এরর এবং সিকিউরিটি অ্যালার্ট লগ এক্সপ্লোরেশন।

Fingerprinting & Domain Lookup WEB
whatweb example.com
👉 টার্গেট ওয়েবসাইট কোন সিএমএস, প্লাগইন, ওয়েব সার্ভার বা ফ্রেমওয়ার্ক ইউজ করছে তা আইডেন্টিফাই করে।
curl -I https://example.com
👉 ওয়েবসাইটের HTTP হেডার রেসপন্স ডেটা এবং সিকিউরিটি ফ্ল্যাগ স্ট্রাকচার এনালাইসিস করে।
whois example.com
👉 ডোমেইন রেজিস্ট্রেশন ডিটেইলস, ওনারশিপ ইনফরমেশন এবং নেমসার্ভার কনফিগারেশন চেক।
nikto -h https://target.com
👉 ওয়েব সার্ভারের মিসকনফিগারেশন এবং আউটডেটেড ফাইল ডিটেকশন ও ডিফেনসিভ অডিট স্ক্যানার।
dig A example.com
👉 ডোমেইনের নির্দিষ্ট IPv4 Mapping বা Address রেকর্ড আইসোলেশন।
subfinder -d example.com
👉 ডিফেনসিভ অডিটের জন্য প্যাসিভ সাবডোমেন ম্যাপিং এবং অ্যাটাক সারফেস রিডাকশন পলিসি।

📶 WiFi Network Management & Verification

শুধুমাত্র নিজের টেস্ট পিসি এবং অথোরাইজড ল্যাব ওয়াইফাই নেটওয়ার্কের ট্রাবলশুটিং প্রোটোকল।

⚠️ Rules Execution Window: অন্যের ওয়াইফাই নেটওয়ার্ক অ্যাক্সেস বা যেকোনো ধরনের অননুমোদিত ইউজেস সম্পূর্ণ অবৈধ। শুধুমাত্র নিজের ডোমেন রিকভারি ও আইটি ট্রাবলশুটিং সেশনে ব্যবহারযোগ্য।
Windows Wireless Profiles Configuration WLAN
netsh wlan show profiles
👉 সিস্টেমে পূর্বে কানেক্ট হওয়া সমস্ত ওয়াইফাই নেটওয়ার্কের সেভড প্রোফাইল নেম লিস্ট রিটার্ন করে।
netsh wlan show profile name="WiFiName"
👉 নির্দিষ্ট ওয়াইফাই প্রোফাইলের ফুল কনফিগারেশন, সিকিউরিটি টাইপ (WPA2/WPA3) এবং ওয়ারলেস সেটিংস রেন্ডার করে।
netsh wlan show profile name="WiFiName" key=clear
👉 নিজের পূর্বে কানেক্টেড নেটওয়ার্কের ভুলে যাওয়া ক্রেডেনশিয়াল রিকভারি লজিক।
Output Extraction Target: Key Content : your_password_here

🧠 How it Works

Windows ওয়ারলেস প্রোফাইল ম্যানেজমেন্ট ডাটাবেস ক্রেডেনশিয়াল সুরক্ষিত অবস্থায় ইন্টারনালি স্টোর করে রাখে। এডমিন প্রিভিলেজসহ key=clear প্যারামিটার পাস করলে উইন্ডোজ সাবসিস্টেম তার ডিস্ক্রিপ্টেড ফর্ম বা সেভড কি প্লেইন টেক্সট আকারে শো করে।
