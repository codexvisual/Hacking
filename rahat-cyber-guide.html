Network Reconnaissance

🌐 Network Recon Commands

নিজের network বোঝার জন্য সব basic থেকে advanced command — বাংলায় ব্যাখ্যাসহ।

📌 Basic Network Info — নিজের device-এর তথ্য WINDOWS
C:\>ipconfig /all
👉 তোমার device-এর IP address, Subnet Mask, Default Gateway, DNS Server, MAC address সব দেখায়। Shows all network adapter details including IP, MAC, DNS ▸ IPv4 Address: 192.168.1.105 | MAC: A4-C3-F0-XX-XX | DNS: 8.8.8.8
C:\>ipconfig /release
👉 DHCP থেকে পাওয়া IP address ছেড়ে দাও। Network reset করার আগে ব্যবহার করো। Releases current DHCP-assigned IP address
C:\>ipconfig /renew
👉 DHCP server থেকে নতুন IP নাও। Release-এর পর ব্যবহার করো। Requests a new IP from DHCP server
C:\>ipconfig /flushdns
👉 DNS cache পরিষ্কার করো। Website access-এ সমস্যা হলে এটি চেষ্টা করো। Clears DNS resolver cache — fixes stale DNS entries
C:\>arp -a
👉 ARP table দেখাও — কোন IP-এর কোন MAC address আছে। Network-এ কারা আছে বুঝতে পারবে। Shows ARP cache — IP to MAC address mapping on your LAN ▸ Interface: 192.168.1.1 → MAC: 18-65-90-XX-XX (router)
C:\>netstat -ano
👉 সব active network connection দেখাও — কোন port open, কোন process ব্যবহার করছে PID সহ। Shows all connections with process IDs — great for finding suspicious connections ▸ TCP 0.0.0.0:443 LISTENING PID:4 | TCP 192.168.1.105:52341 ESTABLISHED
📌 Linux Network Info LINUX / KALI
$ip a
👉 সব network interface-এর IP, MAC address দেখাও। ifconfig-এর নতুন version। Modern replacement for ifconfig — shows all interfaces
$ip route show
👉 routing table দেখাও — packet কোন gateway দিয়ে যাচ্ছে। Shows routing table — which gateway handles which subnet ▸ default via 192.168.1.1 dev eth0 | 192.168.1.0/24 dev eth0
$ip neigh show
👉 ARP cache দেখাও (Linux version)। Local network-এর device গুলো দেখতে পারবে। Shows ARP neighbors on Linux
$hostname -I
👉 শুধু তোমার IP address দেখাও — দ্রুত চেক করতে। Quick way to get your IP address only
$cat /etc/resolv.conf
👉 DNS server configuration দেখাও। Shows configured DNS servers on Linux
📡 Connectivity Check — সংযোগ পরীক্ষা BOTH
$ping google.com -c 4
👉 Internet কাজ করছে কিনা test করো। ৪টি packet পাঠিয়ে response time দেখো। Windows-এ -n 4 ব্যবহার করো। Tests connectivity — -c 4 sends 4 packets (Linux); use -n 4 on Windows ▸ 64 bytes from 142.250.x.x: icmp_seq=1 ttl=118 time=12.5 ms
$ping -t 192.168.1.1
👉 Router-কে continuous ping করো (Windows: -t = infinite)। Ctrl+C দিয়ে থামাও। Continuous ping to router — Windows (-t), Linux (no flag needed)
$traceroute google.com
👉 Data কোন কোন router hop করে গন্তব্যে পৌঁছাচ্ছে দেখাও। Network latency বোঝার জন্য সেরা। Windows-এ tracert। Shows every hop (router) between you and the destination. Windows: tracert ▸ 1: 192.168.1.1 (1ms) → 2: 10.0.0.1 (8ms) → 3: 103.x.x.x (22ms)
$mtr google.com
👉 Traceroute + Ping একসাথে, real-time update। Network troubleshoot-এর সেরা tool। Linux-এ sudo apt install mtr। Real-time combination of traceroute and ping — best for diagnosis
$curl -I https://example.com
👉 Website-এর HTTP header দেখাও। Server কোন software ব্যবহার করছে, status code কত দেখা যাবে। Fetches HTTP headers only — reveals server software, status codes ▸ HTTP/2 200 | Server: cloudflare | X-Frame-Options: DENY
🔍 DNS Analysis — Domain তথ্য BOTH
$nslookup example.com
👉 Domain name → IP address convert করো। কোন DNS server ব্যবহার হচ্ছে তাও দেখাবে। Resolves domain to IP — shows which DNS server answered ▸ Server: 8.8.8.8 | Address: 93.184.216.34
$nslookup -type=MX example.com
👉 Mail server (MX record) বের করো। কোথায় email যাচ্ছে তা বোঝা যায়। Finds mail exchange (MX) records for email routing
$dig example.com
👉 Advanced DNS analysis। A, MX, NS, TXT record সব দেখাবে। Nslookup-এর চেয়ে বেশি তথ্য দেয়। Detailed DNS query — more info than nslookup. Linux/Kali built-in.
$dig example.com ANY +short
👉 সব DNS record সংক্ষেপে দেখাও। Quick overview-এর জন্য। Shows all DNS record types concisely
$dig -x 8.8.8.8
👉 Reverse DNS — IP থেকে hostname বের করো। কোন কোম্পানির IP তা বোঝা যায়। Reverse DNS lookup — IP to hostname ▸ 8.8.8.8.in-addr.arpa → dns.google
$whois example.com
👉 Domain registration তথ্য — কে কিনেছে, কবে expire হবে, registrar কে। Domain registration info — owner, expiry, registrar
Port & Service Discovery

🔎 Port Scanning — LAB ONLY

⚠️ শুধুমাত্র নিজের network বা authorized lab-এ ব্যবহার করো। অনুমতি ছাড়া scanning বেআইনি।

⚠ LAB ONLYনিচের commands শুধু 192.168.x.x (local), VM, বা authorized target-এ চালাও। Public IP-তে scan করা illegal হতে পারে।
🛰 Nmap — Network Mapper (সবচেয়ে শক্তিশালী) LINUX / KALI
$nmap 192.168.1.1
👉 একটি IP-তে basic scan। কোন port open আছে দেখাবে। Basic port scan on a single host ▸ PORT 22/tcp open ssh | 80/tcp open http | 443/tcp open https
$nmap -sV 192.168.1.1
👉 Service version detection — কোন port-এ কোন software কোন version চলছে বের করো। Security audit-এর জন্য গুরুত্বপূর্ণ। Detects service versions running on open ports ▸ 22/tcp open ssh OpenSSH 8.9 | 80/tcp open http Apache 2.4.54
$nmap -sV -O 192.168.1.1
👉 OS detection যোগ করো। কোন operating system চলছে অনুমান করে। Adds OS detection — guesses the target's operating system
$nmap -sC -sV -oN result.txt 192.168.1.1
👉 Default scripts চালাও + result ফাইলে সেভ করো। -sC = default NSE scripts, -oN = output to file। Runs default scripts, detects versions, saves output to file
$nmap -p 80,443,22,3306 192.168.1.1
👉 নির্দিষ্ট port-গুলো চেক করো। Web (80,443), SSH (22), MySQL (3306)। Scans only specific ports — faster and targeted
$nmap -p- 192.168.1.1
👉 সব ৬৫৫৩৫টি port scan করো। সময় লাগে কিন্তু কিছু মিস হয় না। Scans all 65535 ports — thorough but slow
$nmap -sn 192.168.1.0/24
👉 Network-এ কোন কোন device চালু আছে দেখাও (ping scan)। Port scan ছাড়াই। পুরো subnet-এ। Host discovery on entire subnet — shows which devices are online ▸ 192.168.1.1 (router) | 192.168.1.105 (your PC) | 192.168.1.110 (phone)
$nmap --script vuln 192.168.1.1
👉 Known vulnerability check করো (LAB ONLY)। Common CVE গুলো scan করে। Runs vulnerability detection scripts — LAB/authorized targets ONLY
🔌 Port Status — নিজের machine-এ BOTH
$ss -tulpn
👉 কোন port কোন application ব্যবহার করছে দেখাও। -t=TCP, -u=UDP, -l=listening, -p=process, -n=numeric। netstat-এর modern version। Shows all listening ports with their programs — modern netstat ▸ tcp LISTEN 0.0.0.0:80 users:(("nginx",pid=1234))
$ss -tulpn | grep :80
👉 শুধু port 80 ব্যবহার করছে কে দেখাও। grep দিয়ে filter করা। Filters output to show only processes using port 80
C:\>netstat -ano | findstr :443
👉 Windows-এ port 443 কে ব্যবহার করছে দেখাও। findstr = Windows-এর grep। Windows equivalent — filters netstat by port 443
C:\>tasklist /fi "pid eq 4"
👉 নির্দিষ্ট PID-এর process নাম বের করো। netstat-এ PID পেলে এই command দিয়ে process খুঁজে পাও। Finds process name by PID — use PID from netstat output
System Analysis

🖥 System Forensic Commands

Running processes, user sessions, startup items — সব forensic-style analysis।

🏃 Running Processes BOTH
C:\>tasklist
👉 Windows-এ সব চলমান প্রোগ্রাম দেখাও — নাম, PID, memory usage সহ। Lists all running Windows processes with PID and memory ▸ chrome.exe 3421 Console 1 524,312 K
C:\>tasklist /v
👉 Verbose mode — window title, user, CPU time সহ বিস্তারিত দেখাও। Verbose process list with window titles and usernames
C:\>taskkill /PID 1234 /F
👉 নির্দিষ্ট process force-kill করো। Suspicious process বন্ধ করতে। /F = force। Force-kills a process by PID — useful for stopping suspicious processes
$ps aux
👉 Linux-এ সব process দেখাও। a=all users, u=user format, x=no terminal processes। Lists all Linux processes — a=all, u=user-friendly, x=include daemons ▸ USER PID %CPU %MEM COMMAND | root 1 0.0 0.1 systemd
$ps aux | grep apache
👉 শুধু apache-র process দেখাও। যেকোনো process নাম দিয়ে filter করতে পারো। Filters processes by name — replace "apache" with any process
$top
👉 Real-time process monitor। CPU, Memory সব দেখাবে live। q দিয়ে বের হও। htop আরও সুন্দর। Real-time process monitor — press q to exit. htop is more visual.
$kill -9 1234
👉 Linux-এ PID দিয়ে process kill করো। -9 = SIGKILL (force)। Force-kills a process on Linux using SIGKILL signal
👤 User & Session Analysis BOTH
C:\>net user
👉 Windows-এ সব local user account দেখাও। Unauthorized account আছে কিনা check করো। Lists all local Windows user accounts
C:\>net user username /domain
👉 নির্দিষ্ট user-এর বিস্তারিত তথ্য — group membership, last login, password expiry। Detailed info on a specific user — groups, last logon, password status
C:\>query session
👉 কে এখন logged in আছে, কোন session active তা দেখাও। Shows active user sessions on Windows
$who
👉 Linux-এ কে এখন logged in আছে। Shows who is currently logged into the Linux system
$last -n 20
👉 শেষ ২০টি login history দেখাও। কখন কে login করেছে, logout করেছে। Shows last 20 login/logout events — forensic timeline
$cat /etc/passwd | awk -F: '{print $1}'
👉 Linux-এ সব user account-এর list দেখাও। Lists all user accounts on Linux system
💾 Disk & File System BOTH
$df -h
👉 Disk usage দেখাও — কোন partition কতটুকু full। -h = human readable (GB, MB)। Shows disk usage by partition in human-readable format
$du -sh /var/log/*
👉 Log folder-এর size দেখাও। কোন log file অস্বাভাবিক বড় তা ধরা যাবে। Shows size of each log file — large logs may indicate attacks
$find / -mtime -1 -type f 2>/dev/null
👉 গত ২৪ ঘন্টায় modify হওয়া ফাইল খুঁজে বের করো। Suspicious file activity detect করতে। Finds files modified in last 24 hours — detects recent changes
C:\>wmic diskdrive get caption,size
👉 Windows-এ disk drive-এর তথ্য দেখাও। Shows disk drive information on Windows
Blue Team Defense

🛡 Firewall & Defense Commands

নিজের system রক্ষা করো — firewall, iptables, Windows Defender।

🔥 UFW — Linux Firewall (সহজ) LINUX
$sudo ufw status verbose
👉 Firewall-এর বর্তমান অবস্থা দেখাও — কোন rules active আছে। Shows current firewall status and all active rules
$sudo ufw enable
👉 Firewall চালু করো।Enables the UFW firewall
$sudo ufw allow 22/tcp
👉 SSH port 22 allow করো।Opens port 22 for SSH connections
$sudo ufw deny 23/tcp
👉 Telnet port 23 block করো। Telnet insecure — সবসময় block রাখো।Blocks insecure Telnet port — always deny this
$sudo ufw deny from 192.168.1.50
👉 নির্দিষ্ট IP থেকে সব connection block করো।Blocks all traffic from a specific IP address
⚙ iptables — Advanced Linux Firewall LINUX / KALI
$sudo iptables -L -n -v
👉 সব iptables rules দেখাও। -L=list, -n=numeric, -v=verbose। Lists all iptables firewall rules with details
$sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT
👉 Port 80-এ incoming connection allow করো। -A=append, -j ACCEPT=allow। Allows incoming TCP connections on port 80
$sudo iptables -A INPUT -s 10.0.0.5 -j DROP
👉 নির্দিষ্ট IP থেকে সব packet drop করো (silently block)। Silently drops all packets from a specific IP

📡 WiFi Analysis Commands

Wireless network analysis — নিজের network-এর security বোঝার জন্য।

🚨 WARNINGWiFi hacking commands শুধু নিজের router বা authorized lab-এ। অন্যের WiFi-এ করা বেআইনি।
📶 WiFi Info & Scanning BOTH
C:\>netsh wlan show networks
👉 কাছের সব WiFi network দেখাও — SSID, signal strength, encryption type। Shows nearby WiFi networks with security type

👉 একটি saved WiFi-এর password দেখাও (নিজের network হতে হবে)। Reveals saved WiFi password — your own network only!
$iwconfig
👉 Linux-এ wireless interface-এর তথ্য দেখাও। Shows wireless interface configuration on Linux
$sudo iwlist wlan0 scan | grep ESSID
👉 Linux-এ কাছের WiFi network scan করো, শুধু নাম দেখাও। Scans for nearby WiFi networks on Linux, showing only names
$nmcli dev wifi list
👉 Kali/Ubuntu-তে WiFi network সুন্দরভাবে দেখাও — signal, security সহ। Modern way to list WiFi networks on Linux with signal details
Incident Response

📋 Log Analysis Commands

Security logs পড়া — attack detect করার সবচেয়ে গুরুত্বপূর্ণ skill।

📄 Linux System Logs LINUX / KALI
$sudo tail -f /var/log/syslog
👉 System log real-time দেখাও। -f = follow (নতুন entry আসলে দেখাবে)। সমস্যা diagnose করতে। Live-tails the system log — shows new entries as they appear
$sudo cat /var/log/auth.log | grep "Failed password"
👉 SSH login failure দেখাও। Brute-force attack detect করতে পারবে। Finds failed SSH login attempts — detects brute-force attacks ▸ sshd[1234]: Failed password for root from 45.33.x.x port 54321
$sudo grep "Accepted password" /var/log/auth.log
👉 Successful login দেখাও — কে কখন login করেছে। Shows successful logins — check for unauthorized access
$sudo journalctl -xe
👉 systemd journal log দেখাও। Service crash, error সব এখানে থাকে। Views systemd journal with context and explanations
$sudo journalctl -u nginx --since "1 hour ago"
👉 নির্দিষ্ট service-এর শেষ ১ ঘন্টার log দেখাও। Shows nginx logs from the last hour — replace with any service
$sudo cat /var/log/apache2/access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head -10
👉 Apache log থেকে সবচেয়ে বেশি request আসা top 10 IP বের করো। DDoS/scanner detect করতে। Finds top 10 IPs hitting your web server — detects scanners/attacks
📋 Windows Event Log WINDOWS
C:\>eventvwr.msc
👉 Windows Event Viewer GUI খোলো। Security, System, Application log সব এখানে। Opens Windows Event Viewer — GUI for all Windows logs
C:\>wevtutil qe Security /c:20 /rd:true /f:text
👉 Security event log-এর শেষ ২০টি entry command line-এ দেখাও। Shows last 20 Security log entries from command line
C:\>Get-EventLog -LogName Security -Newest 50 | Where-Object {$_.EventID -eq 4625}
👉 PowerShell: শেষ ৫০টির মধ্যে Event ID 4625 (failed login) খুঁজো। PowerShell: finds failed login events (ID 4625) in Security log
